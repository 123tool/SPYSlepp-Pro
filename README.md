## SPYSlepp Pro 🕵️‍♂️📸

**SPYSlepp Pro** adalah aplikasi keamanan Android yang dirancang untuk memberikan lapisan perlindungan tambahan pada perangkat Anda. Aplikasi ini bekerja secara senyap di latar belakang untuk memantau aktivitas pembukaan kunci layar (Unlock) dan secara otomatis mengirimkan dokumentasi visual ke Telegram Anda jika terjadi aktivitas mencurigakan.

## 🚀 Fitur
*   **Silent Capture**: Mengambil foto secara otomatis menggunakan kamera depan tanpa pratinjau (preview) di layar.
*   **Auto Telegram Sync**: Foto hasil tangkapan langsung dikirim ke Bot Telegram pribadi Anda melalui API resmi.
*   **Unlock Trigger**: Aplikasi hanya akan bekerja saat layar perangkat dibuka, menjaga efisiensi baterai dan privasi.
*   **Material Design UI**: Antarmuka yang bersih dan mudah dikonfigurasi langsung dari perangkat.

## 🛠️ Tech Stack
*   **Language**: Java
*   **Environment**: Developed AIDE+ Pro on Android
*   **Design Architecture**: XML Layouts High-Contrast
*   **Communication**: Telegram Bot API
